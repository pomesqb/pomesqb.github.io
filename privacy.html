Privacy Policy

Applies to: Hermes Personal Assistant. Last updated: 16 September 2026.

1. Who this policy covers

Hermes Personal Assistant ("the application") is a single-user, self-hosted personal automation tool. It is installed, operated and used exclusively by its owner on the owner's own private server. It is not offered, sold or made available to any other person, and it has no other users.

2. What data the application accesses

With the owner's explicit OAuth 2.0 consent, the application accesses data belonging to the owner's own Google Account only:

  • Gmail messages, attachments and the ability to send mail as the owner
  • Google Calendar events
  • Google Drive files created or opened by the application
  • Google Docs documents and Google Sheets spreadsheets
  • Google Tasks task lists and tasks
  • Google Contacts, read only

The application does not collect data from anyone other than its owner.

3. How the data is used

Google user data is used for one purpose only: to carry out the tasks the owner personally asks the application to perform - for example searching the owner's own mail, adding an event to the owner's own calendar, writing to the owner's own spreadsheet, or uploading a backup archive to the owner's own Drive.

4. How the data is stored

The application runs on a private server controlled by the owner. OAuth credentials are stored in files readable only by the owner's operating-system account. Any Google user data that is retained is retained locally on that same server, for the owner's own reference. No data is copied to any external service, analytics platform or database.

5. Sharing and transfer

Google user data is never sold, rented, transferred or disclosed to any third party. It is never used for advertising, profiling, market research, or for training or improving any generalised artificial-intelligence or machine-learning model. Data is transmitted only between the owner's own server and Google's official APIs, over encrypted connections.

6. Limited use

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

7. Retention and deletion

The owner may revoke the application's access at any time from the Google Account security settings at myaccount.google.com/permissions. Revoking access immediately stops all further data access. Locally stored credentials and any locally retained data can be deleted by the owner at any time by removing the relevant files from the server.

8. Children

The application is not directed at children and has no users other than its adult owner.

9. Changes to this policy

Any change to this policy will be published on this page, with the "last updated" date above revised accordingly.

10. Contact
